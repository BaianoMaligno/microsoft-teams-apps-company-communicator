# Frontend do Company Communicator

Esta parte veio do template original e foi criada com [Create React App](https://github.com/facebook/create-react-app). Os comandos abaixo são da aplicação cliente. A documentação da implantação e os créditos ficam no README principal do repositório.

## Comandos

Execute na pasta do projeto.

### `npm start`

Abre o modo de desenvolvimento em [http://localhost:3000](http://localhost:3000).
A página recarrega após alterações, e os erros de lint aparecem no console.

### `npm test`

Inicia os testes em modo interativo, acompanhando as alterações.
Veja a documentação de [execução de testes](https://facebook.github.io/create-react-app/docs/running-tests).

### `npm run build`

Gera a versão de produção na pasta `build`, com React em modo de produção, arquivos minificados e hashes nos nomes. Gerar o build não significa que a implantação já foi feita ou validada.

Os detalhes estão no guia de [deploy](https://facebook.github.io/create-react-app/docs/deployment).

### `npm run eject`

**É uma operação sem volta pelo próprio comando.** Ela remove a dependência única de build e copia configurações e dependências de Webpack, Babel, ESLint e demais ferramentas para o projeto.

Os outros comandos continuam funcionando, mas passam a usar as cópias locais. A manutenção dessas configurações fica por sua conta. Não precisa executar `eject` para usar ou desenvolver a aplicação; avalie se essa mudança é necessária antes de fazê-la.
